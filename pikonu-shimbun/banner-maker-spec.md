# ピコぬGIFバナー工房 Ver1.10 仕様書

## 1. 概要

| 項目 | 内容 |
| --- | --- |
| 名称 | ピコぬGIFバナー工房 |
| バージョン | Ver1.10 |
| ファイル | `pikonu-shimbun/banner-maker.html`(1ファイル完結) |
| 目的 | 文字・色・点滅速度・バッジ・サイズを指定して、リンクバナー風のGIF画像を生成・保存する |
| 動作環境 | 最新のPC/スマホブラウザ(Canvas、Blob、URL.createObjectURL対応) |
| 依存 | なし(外部ライブラリ・外部通信なし。Pure HTML/CSS/Vanilla JS) |
| 世界観 | 2001年頃のWindows 98風フリーソフト(ピコぬ新聞社 提供) |

生成はすべてブラウザ内で完結し、入力内容や画像をサーバーへ送信しない。localStorage等も使わない(設定は再読み込みで初期値に戻る)。

## 2. 入力項目

### 2-1. バナー文字

| 項目 | 仕様 |
| --- | --- |
| 文字 | テキストエリア。最大40文字。**2行まで**(3行目以降は無視)。空行は取り除く。空のときは半角スペース扱い |
| バッジ | 最大8文字。空欄でバッジなし |
| バッジのプリセット | (なし)/NEW!/おすすめ!/広告募集中!/UP!/キリ番!/自由入力。選ぶとバッジ欄に文言が入る |

### 2-2. サイズ・色・点滅

| 項目 | 仕様 |
| --- | --- |
| サイズ(プリセット) | 88×31 リンクバナー(初期値)/120×60 ミニバナー/200×40/234×60 ハーフバナー/468×60 フルバナー/自由入力 |
| 幅×高さ | 数字入力。幅16〜600、高さ16〜200。範囲外・数字以外は範囲内の値に補正(数字以外は初期値88×31)。プリセットに一致しない値を入れると、プリセット欄は「自由入力」に切り替わる |
| 背景色 | カラーピッカー。初期値 `#0000cc` |
| 文字色 | カラーピッカー。初期値 `#ffffff` |
| 点滅速度 | 静止/ゆっくり(1秒)/ふつう(0.5秒、初期値)/はやい(0.25秒)/超はやい(0.1秒) |
| 枠線 | チェックボックス。初期値ON。色は文字色と同じ、太さ1px |

バッジの色は固定(地=赤 `#ff0000`、文字=黄 `#ffff00`)。

## 3. 出力

| 項目 | 仕様 |
| --- | --- |
| 形式 | GIF89a(アニメーションGIF) |
| サイズ | 指定した幅×高さ(ピクセル) |
| コマ数 | 静止=1コマ、それ以外=2コマ |
| 表示時間 | 1コマあたり 100/50/25/10(1/100秒単位)。静止時は100 |
| ループ | 2コマのとき無限ループ(NETSCAPE2.0拡張) |
| 色数 | 16色(グローバルパレット、透明色なし) |
| ファイル名 | `banner-{幅}x{高さ}.gif`(例: `banner-88x31.gif`) |
| 目安サイズ | 88×31で数百バイト〜1KB程度 |

### プレビュー

- 実寸表示を必ず出す。
- 拡大表示は、倍率 = `floor(352 ÷ 幅)` が2以上のとき(幅176以下)だけ出す。それ以上の幅では非表示。拡大はドットを潰さない表示(`image-rendering: pixelated`)。
- 「保存(S)」ボタンで保存。画像の右クリック保存も可能。
- 入力を変更するたびに、自動で再生成する(ボタン操作は不要)。

## 4. レイアウト仕様

以下、幅=W、高さ=H。

| 項目 | 計算 |
| --- | --- |
| 内側の余白 x0 | 枠線あり=2px、なし=1px |
| 内側の幅 bw | W − x0×2 |
| バッジ帯の高さ th | round(H × 0.35)(H=31で11px) |
| バッジ帯の位置 | y=2 から th 行分。文字は帯に収まるよう最大 th−1 px の太字 |
| バッジの地の幅 | min(bw, バッジ文字幅+4)。左右中央に置く |
| 本文エリアの上端 | バッジあり=2+th、なし=x0 |
| 本文エリアの下端 | H − x0 |
| 本文の最大文字サイズ | バッジあり=round(H×0.52)、なし=round(H×0.71)。太字 |
| 本文の最小文字サイズ | max(6, round(H × (2行なら0.26、1行なら0.32))) |

文字はすべて中央寄せ。2行のときは、エリアを2等分して各行を中央に置く。

### 文字サイズの決め方

1. 最大サイズ(と、行数で割ったエリア高さのうち小さいほう)から始める。
2. 最も長い行の幅がエリア幅に収まるまで、1pxずつ小さくする。
3. 最小サイズまで下げても収まらないときは、**横方向だけを縮めて**(つぶして)収める。

## 5. 描画・色の仕様

### 5-1. 文字の描画(スーパーサンプリング)

1. 4倍の大きさ(W×4 × H×4)のキャンバスに、黒で文字を描く。
2. 4×4ピクセルごとに透明度を平均し、1.3倍に強調(上限1)する。
3. 0〜7の8段階に丸めて、濃淡マスクとする。

小さい文字を直接描くとにじむ・線が欠けるため、この方式にしている。

### 5-2. パレット(16色)

| 番号 | 内容 |
| --- | --- |
| 0〜7 | 背景色 → 文字色を8段階で混ぜた色。0=背景色、7=文字色 |
| 8〜15 | バッジの地(赤) → バッジ文字(黄)を8段階で混ぜた色。8=赤、15=黄 |

### 5-3. コマの構成

**通常コマ**

- 全面を番号0(背景色)で塗る。
- 枠線ありなら、外周1pxを番号7(文字色)にする。
- バッジがあれば、地を番号8、文字を「8+濃淡」で塗る。
- 本文を「濃淡」の番号で塗る。

**反転コマ**(点滅するときのみ)

- 全面を番号7で塗る(背景と文字の色が入れ替わる)。
- バッジの地は番号15、文字は「15−濃淡」。
- 本文は「7−濃淡」。
- 枠線は番号7のままなので、反転コマでは背景に溶けて見えなくなる。

## 6. GIFエンコード仕様

- ヘッダー `GIF89a`、論理画面=指定サイズ。
- グローバルカラーテーブル16色(packed=`0xF3`)。
- 2コマのときのみ NETSCAPE2.0 のループ拡張(無限)を出力。
- 各コマ: Graphic Control Extension(disposal=1、遅延時間、透明なし)+ Image Descriptor(全面)+ LZW圧縮データ。
- LZW最小コードサイズ=4。辞書が4096に達したらクリアコードを出してリセットする。
- データは255バイトごとのサブブロックに分割し、最後に `0x3B`(終端)。
- 自前のエンコーダで生成し、外部ライブラリは使わない。

## 7. 画面構成(2001年風UI)

- 背景: ティール(水色がかった緑)。
- Windows 98風のウィンドウ: 青いグラデーションのタイトルバー、ダミーの最小化・最大化・閉じるボタン、メニューバー(ファイル/編集/表示/ヘルプ。**見た目のみで機能なし**)、ステータスバー。
- 入力部は3つのグループボックス: 「1. バナー文字」「2. サイズ・色・点滅」「3. できあがり」。
- 「バージョン情報」ボタンでダイアログを表示(名称、Ver1.10、(C)ピコぬ新聞社 2001、フリーソフトである旨)。
- フォントは `ＭＳ Ｐゴシック` 系の指定。

## 8. 制約・注意事項

- **フォントは閲覧端末に依存する。** 指定の日本語フォントが無い環境では、代替フォントで描画される。
- 88×31のような小さいサイズでは、バッジをつけると本文の高さが減り、文字が小さくなる。読みたい文字が多いときはバッジなしを推奨。
- 文字配置は中央寄せ固定。左寄せ・右寄せ、文字色の個別指定(縁取り等)はできない。
- コマは最大2つ。色の入れ替わりによる点滅のみで、ほかのアニメーション(スクロール等)はない。
- 16色のため、写真やグラデーションを取り込む機能はない。
- 一部のブラウザは、極端に短い表示時間を無視して遅くする場合がある(最短は0.1秒に設定済み)。
- 高さ・幅の上限(600×200)を超えるサイズは作成できない。
- メニューバーは飾りで、クリックしても何も起きない。

## 9. 検証状況

- GIFエンコーダは、88×31、234×60、468×60、600×200のテスト画像(2コマ、16色)を書き出し、別のツールで読み直して全コマの画素が一致することを確認した。
- 画面上のレイアウト・文字の見え方は、88×31(バッジあり/なし)でのスクリーンショット確認まで。**88×31以外のサイズでの見た目は、未確認。**
